# AIPM Coach Runtime Data

本目录保存 AIPM Coach 在当前工作区产生的本地数据。仓库只提供空白结构，不包含作者的个人学习记录、真实会话或能力历史。

- `knowledge-notes/`：用户确认后的知识笔记；
- `knowledge-index.md`：知识笔记索引；
- `session-drafts/`：完整 workflow 收尾前的 session 草稿；
- `session-runs/`：通过校验的真实 workflow session；
- `capability-radar/`：能力雷达图、完整历史和最近五次窗口；
- `coach-policy/active-lessons.md`：经过证据门禁后生效的教练自我改进规则；
- `improvement-backlog.jsonl`：待筛选的教练改进候选项，由脚本按需创建。

这些文件可能包含个人项目、学习反思和能力判断。生成内容默认由 `.gitignore` 排除，请不要未经检查上传。
